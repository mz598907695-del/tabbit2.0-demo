# Tabbit 窗口主题染色实现说明

更新日期：2026-11-16

所有百分比均指**不透明度**，数值越大颜色越实。实际 60% 即 `alpha = 0.6`。

## 图层顺序

从底到上：**固定原生标准玻璃 → 主题染色层（或壁纸）→ 全局渐变叠层 → 界面内容**。

主题颜色和浓度只控制染色层，玻璃底层保持固定。

## 主题染色数据

| 主题 | 浅色色值 | 深色色值 |
|---|---|---|
| 默认 | `#F2F7FF` | `#404040` |
| 橙色 | `#FFAA00` | `#B37700` |
| 黄色 | `#FFE007` | `#C6AE07` |
| 绿色 | `#6DEB36` | `#4BA525` |
| 青色 | `#00C7FC` | `#008DB3` |
| 蓝色 | `#3A88FE` | `#245CB0` |
| 紫色 | `#B188FF` | `#7E61BC` |
| 粉色 | `#F6A8FF` | `#B079B9` |

所有主题的默认实际不透明度：

- 浅色：**60%**，即 `alpha = 0.6`。
- 深色：**40%**，即 `alpha = 0.4`。

## 滑杆映射

用户滑杆显示 0～100%，对应实际不透明度 20～80%。

| 用户滑杆 | 实际不透明度 |
|---|---|
| 0% | 20% |
| 100% | 80% |

```text
实际不透明度（%）= 20 + 用户滑杆值 × 0.6
用户滑杆值 =（实际不透明度 − 20）÷ 0.6
```

默认滑杆位置：浅色 **66.67%**，深色 **33.33%**。内部保留精度，确保实际默认值精确为 60% 和 40%。

## 全局渐变叠层

位于主题染色层（或壁纸）上方，从上到下渐变；独立于染色浓度滑杆，使用普通叠加。

```css
/* 浅色：顶部 85%，100% 位置保留 10% 不透明度 */
linear-gradient(
  180deg,
  rgba(245, 245, 245, 0.85) 0%,
  rgba(245, 245, 245, 0.1) 100%
)

/* 深色：顶部 70%，底部 20% 不透明度 */
linear-gradient(
  180deg,
  rgba(26, 26, 26, 0.7) 0%,
  rgba(26, 26, 26, 0.2) 100%
)
```
